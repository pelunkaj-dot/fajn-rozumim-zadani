# První hratelný základ

Otevři `index.html` v prohlížeči; aplikace nepotřebuje instalaci ani server. Pro stabilní ukládání pokroku doporučujeme webový hosting. Veškeré údaje zůstávají v localStorage daného prohlížeče.

Obsahuje devět nezávisle dostupných úvodních misí, dvě uznané strategie pro každou, možnost návratu, dobrovolný početní bonus, kontrolu reality, přetahování ptáků a klikací alternativu, vypínatelné syntetické zvuky a čtení zadání podle dostupných hlasů prohlížeče.

Nejde ještě o devět hotových světů ani 900 úloh. Barva na mapě značí pouze splnění úvodního sektoru, nikoli celého ročníku. Zbývá doplnit tematické ilustrace, skutečné stavební fáze a animace materiálů, manipulativní modely pro vyšší ročníky, další mise a podrobnější diagnostiku. Současná stavba je pouze symbolická. Obě alternativní cesty jsou zatím vysvětleny textově, nikoli vyhodnocovány jako libovolný sled žákových kroků.

Kontroly: `node --check app.js` a `node test.cjs`. Test používá jednoduchou náhradu DOM; není náhradou vizuálního a dotykového testu v prohlížeči.

Původní README je zachováno. Hosting ani GitHub Pages nebyly nastaveny.
